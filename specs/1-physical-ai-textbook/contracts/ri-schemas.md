# RI Object Schemas: Physical AI & Humanoid Robotics Textbook

**Branch**: `1-physical-ai-textbook` | **Date**: 2025-12-05 | **Spec**: specs/1-physical-ai-textbook/spec.md

## Summary

This document defines the interface (schema) for each Reusable Intelligence (RI) object used within the textbook content. These schemas ensure consistency and enable automated processing and generation of content elements.

## RI Object Schemas

### 1. `ri.GlossaryGenerator` Schema
- **Purpose**: Defines a single glossary term and its properties.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "term": {"type": "string", "description": "The canonical term to define.", "unique": true},
      "definition": {"type": "string", "description": "The detailed explanation of the term."},
      "module": {"type": "string", "description": "Optional: The module where this term is primarily introduced.", "nullable": true},
      "chapter": {"type": "string", "description": "Optional: The chapter where this term is primarily introduced.", "nullable": true}
    },
    "required": ["term", "definition"]
  }
  ```

### 2. `ri.RobotDiagram` Schema
- **Purpose**: Defines properties for embedding a standardized robot diagram.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "diagramId": {"type": "string", "description": "Unique identifier for the diagram.", "unique": true},
      "altText": {"type": "string", "description": "Alternative text for accessibility.", "minlength": 10},
      "filePath": {"type": "string", "description": "Absolute path to the image file, e.g., /static/img/moduleX_chapterY_diagramZ.png.", "pattern": "^/static/img/.*\\.(png|jpg|jpeg|gif|svg)$"},
      "caption": {"type": "string", "description": "Formatted caption for the figure, generated by ri.FigureCaptionTemplate.", "minlength": 10}
    },
    "required": ["diagramId", "altText", "filePath", "caption"]
  }
  ```

### 3. `ri.WarningBlock` Schema
- **Purpose**: Defines properties for a standardized warning or note block.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "type": {"type": "string", "enum": ["Safety", "Important", "Note"], "description": "The type of warning.", "default": "Note"},
      "content": {"type": "string", "description": "The Markdown/MDX content of the warning message.", "minlength": 10}
    },
    "required": ["type", "content"]
  }
  ```

### 4. `ri.CodeExampleTemplate` Schema
- **Purpose**: Defines properties for a standardized code example block.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "language": {"type": "string", "description": "Programming language for syntax highlighting (e.g., python, cpp, bash)."},
      "codeBlock": {"type": "string", "description": "The actual code content.", "minlength": 1},
      "explanation": {"type": "string", "description": "Markdown/MDX explanation of the code, line-by-line or block-by-block.", "minlength": 20},
      "expectedOutput": {"type": "string", "description": "Optional: Expected output of the code, if runnable.", "nullable": true},
      "hardwareWarnings": {"type": "boolean", "description": "Indicates if hardware-related warnings (using ri.WarningBlock) should be included.", "default": false}
    },
    "required": ["language", "codeBlock", "explanation"]
  }
  ```

### 5. `ri.FigureCaptionTemplate` Schema
- **Purpose**: Defines properties for a standardized figure caption.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "figureNumber": {"type": "integer", "description": "The sequential figure number within the chapter.", "minimum": 1},
      "title": {"type": "string", "description": "A concise title for the figure.", "minlength": 5},
      "description": {"type": "string", "description": "A brief description explaining the figure.", "minlength": 10}
    },
    "required": ["figureNumber", "title", "description"]
  }
  ```

### 6. `ri.PageMetadata` Schema
- **Purpose**: Defines Docusaurus front-matter metadata for content pages.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "title": {"type": "string", "description": "Page title.", "minlength": 5},
      "description": {"type": "string", "description": "SEO description.", "minlength": 20},
      "keywords": {"type": "array", "items": {"type": "string"}, "description": "List of keywords for search/SEO.", "minItems": 3},
      "sidebar_label": {"type": "string", "description": "Label shown in sidebar.", "minlength": 3},
      "sidebar_position": {"type": "integer", "description": "Order in sidebar.", "minimum": 1},
      "slug": {"type": "string", "description": "URL slug for the page.", "pattern": "^[a-z0-9-]+$"}
    },
    "required": ["title", "description", "keywords", "sidebar_label", "sidebar_position", "slug"]
  }
  ```

### 7. `ri.ExerciseTemplate` Schema
- **Purpose**: Defines properties for a standardized end-of-chapter exercise.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "exerciseNumber": {"type": "integer", "description": "Sequential exercise number.", "minimum": 1},
      "difficulty": {"type": "string", "enum": ["Beginner", "Intermediate", "Advanced"], "description": "Difficulty level."},
      "description": {"type": "string", "description": "Markdown/MDX description of the exercise.", "minlength": 20},
      "learningObjectiveRef": {"type": "string", "description": "Reference to the learning objective this exercise addresses.", "minlength": 5},
      "solution": {"type": "string", "description": "Optional: Markdown/MDX content for the solution, or a path to a solution file.", "nullable": true}
    },
    "required": ["exerciseNumber", "difficulty", "description", "learningObjectiveRef"]
  }
  ```

### 8. `ri.LabTask` Schema
- **Purpose**: Defines properties for a standardized practical lab assignment.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "labId": {"type": "string", "description": "Unique ID for the lab task.", "unique": true},
      "title": {"type": "string", "description": "Title of the lab assignment.", "minlength": 5},
      "objective": {"type": "string", "description": "Markdown/MDX description of the lab's objective.", "minlength": 20},
      "prerequisites": {"type": "array", "items": {"type": "string"}, "description": "List of required prior knowledge or completed sections/chapters.", "minItems": 1},
      "equipment": {"type": "array", "items": {"type": "string"}, "description": "List of physical or software equipment needed.", "minItems": 1},
      "steps": {"type": "array", "items": {"type": "string"}, "description": "Ordered list of steps to complete the lab.", "minItems": 1},
      "deliverables": {"type": "array", "items": {"type": "string"}, "description": "List of expected outputs or submissions from the lab.", "minItems": 1},
      "assessmentCriteria": {"type": "string", "description": "Markdown/MDX description of how the lab will be assessed.", "minlength": 20}
    },
    "required": ["labId", "title", "objective", "prerequisites", "equipment", "steps", "deliverables", "assessmentCriteria"]
  }
  ```

### 9. `ri.CapstoneMilestone` Schema
- **Purpose**: Defines properties for a standardized capstone project milestone.
- **Schema Definition**:
  ```json
  {
    "type": "object",
    "properties": {
      "milestoneId": {"type": "string", "description": "Unique ID for the capstone milestone.", "unique": true},
      "title": {"type": "string", "description": "Title of the capstone milestone.", "minlength": 5},
      "description": {"type": "string", "description": "Markdown/MDX description of the milestone.", "minlength": 20},
      "objectives": {"type": "array", "items": {"type": "string"}, "description": "Key objectives for this milestone.", "minItems": 1},
      "deliverables": {"type": "array", "items": {"type": "string"}, "description": "List of expected outputs/submissions for this milestone.", "minItems": 1},
      "evaluationMetrics": {"type": "string", "description": "Markdown/MDX description of how this milestone will be evaluated.", "minlength": 20}
    },
    "required": ["milestoneId", "title", "description", "objectives", "deliverables", "evaluationMetrics"]
  }
  ```
