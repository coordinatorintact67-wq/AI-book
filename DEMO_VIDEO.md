## Recording Tips

1. **Screen Recording:**
   - Use OBS Studio or Loom
   - Record at 1080p, 30fps
   - Clean browser window (no extensions visible)

2. **Pacing:**
   - Practice transitions beforehand
   - Keep mouse movements smooth
   - Use zoom for code examples

3. **Audio:**
   - Record in quiet environment
   - Use microphone if possible
   - Speak clearly and energetically

4. **Editing:**
   - Add smooth transitions between scenes
   - Include background music (optional)
   - Add text overlays for key features

5. **Backup Plan:**
   - If live demo fails, use screenshots
   - Have recorded clips ready
   - Test all features before recording
